# 代码 Agent 项目资料中心

这里是代码 Agent 和项目维护者的工作入口，记录**当前可核验事实、操作方式、设计细节与历史演进**。它不是面试背诵材料。

如果本目录与代码或测试冲突，应先核对代码与测试，再修正文档；不能用设计稿或归档文件反向证明功能已经实现。

代码 Agent 开始新任务时，先遵守根目录 `AGENTS.md`，读取 `.codex/SESSION_STATE.md` 并检查 Git 状态，再进入本页定位项目资料。本页负责资料导航，不替代项目协作约定或当前任务交接。

## 优先读取顺序

| 顺序 | 文档 | 用途 |
|---:|---|---|
| 1 | [项目总览](./项目总览.md) | 确认项目定位、架构、已实现能力与当前边界 |
| 2 | [运行与排错](./运行与排错.md) | 安装、配置、启动、测试和故障处理 |
| 3 | [手动验收测试清单](./手动验收测试清单.md) | 按样例逐项验收 Web UI、Agent、RAG、记忆、动作与传输协议 |
| 4 | [接口说明](./接口说明.md) | HTTP、SSE、WebSocket 及请求响应协议 |
| 5 | [项目证据](./项目证据.md) | 自动化测试、专项评测与真实链路证据 |

代码 Agent 开始新任务时，不必通读全部专题。先通过上面五篇定位所需事实，再按改动范围进入对应目录；仅做代码分析时不必执行整份手动清单。

## 专题分区

| 分区 | 负责内容 | 何时更新 |
|---|---|---|
| [technical](./technical/README.md) | 路由、RAG、动作分析、工具注册等深入设计与接入状态 | 对应模块设计或实现变化时 |
| [optimization](./optimization/README.md) | 记忆、上下文压缩和工程演进 | 记忆或上下文机制变化时 |
| [miniprogram](./miniprogram/README.md) | 微信小程序实现、端侧设计与验收边界 | 小程序代码或联调状态变化时 |
| [superpowers](./superpowers/README.md) | 项目早期规格与实施计划归档 | 原则上只保留，不作为当前事实修改 |
| [旧版面试归档](./technical/interview-archive/README.md) | 已退出学习主线的旧材料 | 只用于历史追溯 |

## 与学习资料的边界

- 需要理解项目或准备面试：进入[用户学习中心](../learning/README.md)。
- 修改简历口径：维护[简历项目描述与防守边界](../learning/09_简历项目描述与防守边界.md)，并先核对本目录事实。
- 新增简历技术点：同时在[简历技术点总表](../learning/03_简历技术点总表.md)补充可学习、可追问的解释。
