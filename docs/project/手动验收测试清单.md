# 手动验收测试清单

本文档用于在本地逐项验收项目的启动、Web UI、模型选择、Agent 路由、RAG、联网搜索、记忆、动作分析以及 HTTP/SSE/WebSocket 传输能力。它记录的是**如何验证**，不是已经通过的证据；实际通过情况应填写在文末记录表，稳定结论再同步到[项目证据](./项目证据.md)。

## 0. 验收口径

测试结果按以下三类记录，避免把降级演示误当成真实能力：

| 标记 | 含义 |
|---|---|
| `PASS` | 实际结果符合预期 |
| `DEGRADED` | 主流程可用，但明确走 mock、fallback 或低能力模式 |
| `FAIL` | 返回异常、结果与执行轨迹矛盾，或页面交互不可用 |

重点查看每次 Agent 响应中的：

- `intent`：路由识别出的主意图。
- `sources`：RAG 的知识文件名或搜索结果 URL。
- `warnings`：非致命异常与降级说明。
- `execution`：实际使用的组件、模式和是否降级。

以下情况属于当前设计边界，不应直接判为故障：

- `MCP_SERVER_COMMAND=mock` 时，`mcp/mock/degraded=true` 是预期结果，只能证明路由、工具协议封装和降级链路可用，不能证明接通了真实 MCP Server。
- 未传动作素材时，`motion/guidance_only/degraded=true` 是文字指导模式。
- 视频未传 `reference_name` 时只做姿态序列提取，`metrics=null`；这不等于完成了标准动作相似度比较。
- `MEMORY_VECTOR_ENABLED=false` 时，记忆向量任务处理器返回未启用是正常结果；当前短期会话和 SQLite 长期记忆仍可使用。
- 显式选择不可用的本地 Qwen 时应返回 `503`，系统不会静默改用 DeepSeek。

## 3. PowerShell 测试助手

后续 API 样例默认已设置 `$base`，并定义：

```powershell
$base = "http://127.0.0.1:8000"

function Send-AgentMessage {
    param(
        [string]$UserId,
        [string]$Message,
        [string]$Model = "deepseek-api",
        [string]$ConversationId = ""
    )

    $payload = @{
        user_id = $UserId
        message = $Message
        model = $Model
    }
    if ($ConversationId) {
        $payload.conversation_id = $ConversationId
    }

    Invoke-RestMethod `
        -Method Post `
        -Uri "$base/chat" `
        -ContentType "application/json; charset=utf-8" `
        -Body ($payload | ConvertTo-Json)
}
```

每个场景使用不同 `user_id`，防止旧历史和长期记忆干扰判断。

- [ ] 选择 `DeepSeek（API）` 后刷新页面，选择仍被浏览器保留。

### UI-02 输入与发送

- [ ] 点击快捷卡片能生成对应问题或发起对应能力。
- [ ] `Enter` 发送，`Shift+Enter` 换行。
- [ ] 连续输入多行时输入框向上增高；达到最大高度后才在输入框内部滚动。
- [ ] 空白内容不能发送。
- [ ] 请求进行中发送按钮和状态反馈合理，不会重复提交同一条消息。
- [ ] 发送足够长的回答后，页面整体高度保持不变，只有中间消息区出现纵向滚动；可以从回答底部滚回开头，底部输入框仍固定可见。

### UI-03 流式回答与结果信息

发送：

```text
什么是渐进超负荷？请用三点说明。
```

- [ ] 回答逐步显示，而不是页面冻结到最后一次性出现。
- [ ] 完成后能看到意图/能力、来源、警告或执行模式中的适用信息。
- [ ] 回答复制按钮可用，复制内容与正文一致。
- [ ] 服务端错误会显示为可理解的错误消息，不残留永久“生成中”状态。
- [ ] 流式生成时停留在底部会自动跟随新内容；主动向上滚动后，后续内容不会强行抢回底部，重新滚到底部后恢复自动跟随。

### UI-04 会话与刷新恢复

- [ ] 连续发送两条消息后刷新页面，当前会话能够恢复。
- [ ] 点击“新聊天”后创建独立空会话，旧会话仍保留在“最近”列表中。
- [ ] 在两个会话间切换时消息互不串线，刷新后仍能恢复当前选择。
- [ ] 输入关键字能过滤最近会话，点击清除后恢复完整列表。
- [ ] 点击任一会话右侧“…”能完整看到“重命名”和“删除”；列表底部会话的菜单不会被滚动区域裁剪。
- [ ] 重命名后侧栏标题与顶部标题同步更新。
- [ ] 删除非当前会话不影响当前对话；删除当前会话后自动切换到其他会话或新建空会话。
- [ ] 新会话发送第一条用户消息后，标题自动更新为消息摘要。

### UI-05 附件

- [ ] 点击回形针可选择支持的图片或视频。
- [ ] 选择后显示文件预览或文件信息。
- [ ] 删除附件后可继续发送纯文本。
- [ ] 上传图片后显示姿态分析结果或明确的 422/503 原因。
- [ ] 上传视频后显示姿态提取结果；当前 Web UI 未选择标准参考时，不应伪造相似度分数。
- [ ] 不支持的扩展名或超限文件会显示明确错误。

### UI-06 响应式与异常恢复

使用浏览器开发者工具切换到约 `390 × 844`：

## 8. 会话、短期记忆与长期记忆

### MEMORY-01 最近对话

```powershell
$first = Send-AgentMessage `
  -UserId "manual-short-memory" `
  -Message "我每周训练三次。"

$conversationId = $first.conversation_id

Send-AgentMessage `
  -UserId "manual-short-memory" `
  -ConversationId $conversationId `
  -Message "我刚才说每周训练几次？" |
  ConvertTo-Json -Depth 8
```

- [ ] 第二次回答“三次”。
- [ ] 两次响应的 `conversation_id` 相同。

查看和清除会话：

```powershell
Invoke-RestMethod "$base/chat/manual-short-memory/history" |
  ConvertTo-Json -Depth 8

Invoke-RestMethod `
  -Method Delete `
  -Uri "$base/chat/manual-short-memory/history"
```

- [ ] 历史接口能返回该用户最近一个活跃会话的消息。
- [ ] 清除后该用户的活跃历史不再恢复。该接口按用户归档会话，不是按单个 `conversation_id` 删除。

### MEMORY-02 显式普通偏好

```powershell
Send-AgentMessage `
  -UserId "manual-explicit-memory" `
  -Message "请记住：我不吃香菜。" |
  ConvertTo-Json -Depth 8

Invoke-RestMethod "$base/memory?user_id=manual-explicit-memory" |

```

- [ ] 普通明确偏好可成为有效长期记忆。
- [ ] 后续饮食建议避开香菜。

### MEMORY-03 隐式低风险信息累积独立证据

```powershell
$firstObservation = Send-AgentMessage `
  -UserId "manual-candidate" `
  -Message "我平时每周训练三次。"
$firstObservation | ConvertTo-Json -Depth 8

$observationResponse = Invoke-RestMethod `
  "$base/memory/observations?user_id=manual-candidate&status=open"
$observationResponse | ConvertTo-Json -Depth 8
```

- [ ] 第一条稳定隐式信息进入 `observed`，包含来源、置信度、证据数和过期时间。
- [ ] 此时不在正式长期记忆中；若满足软注入阈值，也只能作为“不确定线索”影响回答。

同一会话重复表达不应满足“跨会话证据”：

```powershell
Send-AgentMessage `
  -UserId "manual-candidate" `
  -ConversationId $firstObservation.conversation_id `
  -Message "我平时每周训练三次。" | Out-Null

Invoke-RestMethod "$base/memory?user_id=manual-candidate" |
  ConvertTo-Json -Depth 8
```

- [ ] 尚未自动晋升。

新建另一会话并再次表达：

```powershell
$newConversation = Invoke-RestMethod `
  -Method Post `
  -Uri "$base/chat/manual-candidate/conversations"

Send-AgentMessage `
  -UserId "manual-candidate" `
  -ConversationId $newConversation.id `
  -Message "我平时每周训练三次。" | Out-Null

Invoke-RestMethod "$base/memory?user_id=manual-candidate" |
  ConvertTo-Json -Depth 8
```

- [ ] 达到默认的 2 份独立会话证据和 0.82 置信度后，低风险信息自动进入正式长期记忆。
- [ ] 重复同一消息来源不会重复计数；如果规则未识别该句式，应记录为提取边界，而不是人工伪造通过。

人工拒绝可用另一个用户复测：

```powershell
Send-AgentMessage `
  -UserId "manual-candidate-reject" `
  -Message "我平时喜欢清晨训练。" | Out-Null

$rejectResponse = Invoke-RestMethod `
  "$base/memory/observations?user_id=manual-candidate-reject&status=open"
$rejectItem = $rejectResponse.observations |
  Select-Object -First 1

Invoke-RestMethod `
  -Method Post `
  -Uri "$base/memory/observations/$($rejectItem.id)/reject?user_id=manual-candidate-reject"
```

- [ ] 拒绝后 observation 状态更新，且不会再软注入或进入活跃长期记忆。

### MEMORY-04 健康敏感信息

```powershell
Send-AgentMessage `
  -UserId "manual-sensitive-memory" `
  -Message "请记住：我右膝有旧伤，训练时避免跳跃动作。" |
  ConvertTo-Json -Depth 8

Invoke-RestMethod "$base/memory/candidates?user_id=manual-sensitive-memory" |
  ConvertTo-Json -Depth 8
```
